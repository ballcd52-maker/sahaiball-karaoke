# 🎤 Smart Web Karaoke System (ระบบคาราโอเกะ 2 จอ สั่งเพลงผ่านมือถือ)

ระบบเว็บแอปพลิเคชันคาราโอเกะเต็มรูปแบบ ออกแบบสำหรับการร้องเพลงในบ้านหรือห้องคาราโอเกะส่วนตัว รองรับการทำงานแบบ **2 หน้าจอ (จอทีวี + จอมือถือ)**, ค้นหาเพลงจาก **YouTube โดยไม่มีโควต้าจำกัด**, สลับและตัดเสียงร้อง, และซิงค์คิวเพลงแบบ Real-time ผ่าน WebSocket

---

## 🌟 จุดเด่นและฟีเจอร์หลัก

1. **📺 หน้าจอทีวี (TV Display - `/display`)**:
   - รองรับ Full HD / 4K บนทีวี เช่น Sony KD-55X8500G หรือจอที่ 2 ของคอมพิวเตอร์
   - แสดงผลวิดีโอ MV คาราโอเกะแบบไร้โฆษณาแทรกกวนใจ
   - มีแบนเนอร์แสดงชื่อเพลง, ชื่อคนขอเพลง (`👤 ขอโดย: ...`), และคิวเพลงถัดไป
   - ระบบ **Danmaku / Live Reactions**: ข้อความและอีโมจิเชียร์ลอยข้ามจอทีวีแบบสดๆ
   - มี **QR Code** ขึ้นมุมจอ ให้เพื่อนในห้องเปิดกล้องสแกนสั่งเพลงได้ทันที

2. **📱 หน้ารีโมทสั่งเพลงผ่านมือถือ (Mobile Remote - `/remote`)**:
   - ออกแบบ UI ให้เหมือนแอปมือถือ ใช้งานสะดวกบน iPhone / Android / แท็บเล็ต
   - **ระบบค้นหาเพลง**: พิมพ์ชื่อเพลง/ศิลปิน ดึงคลิปจาก YouTube แบบ Real-time พร้อมปุ่มคัดกรอง "🎯 เน้นเพลงคาราโอเกะ"
   - **ระบบต่อคิว (Queue Management)**:
     - ปุ่ม `+ ต่อคิว`: เพิ่มเพลงต่อท้าย
     - ปุ่ม `⚡ ร้องเลย (Priority Queue)`: แซงคิวขึ้นมาเป็นเพลงถัดไปทันที
     - สลับลำดับคิวขึ้น/ลง หรือลบเพลงที่ไม่ต้องการ
   - **แผงควบคุม KTV**:
     - เล่น / หยุดชั่วคราว / ข้ามเพลง / เริ่มเพลงใหม่ตั้งแต่ต้น
     - ปรับระดับเสียง (Volume Slider)
   - **🎙️ ระบบสลับและตัดเสียงร้อง (Vocal Controls)**:
     - `สลับเป็นเวอร์ชันดนตรี (Karaoke Swap)`: สลับคลิปเป็นเวอร์ชันดนตรีคาราโอเกะให้อัตโนมัติ
     - `ตัดเสียงร้อง (Vocal Suppression)`: ลดเสียงร้องตรงกลางของเพลง
   - **🎉 ส่งสติกเกอร์ & เชียร์สด**:
     - กดอีโมจิ (🎤, ❤️, 👏, 🔥, 🍻) หรือพิมพ์ข้อความให้วิ่งบนจอทีวี

## 🚀 วิธีเปิดใช้งาน

### 1. วิธีเริ่มรันระบบ
ดับเบิลคลิกที่ไฟล์:
```
c:\Users\XXX\Documents\antigravity\modest-salk\karaoke-web\start-karaoke.bat
```
หรือรันผ่าน Terminal:
```bash
cd karaoke-web
node server.js
```

### 2. ลิงก์สำหรับการเข้าใช้งาน
- **หน้าหลัก (Portal Hub)**: `http://localhost:3000`
- **หน้าจอทีวี (TV Screen)**: `http://localhost:3000/display`
- **หน้ารีโมทมือถือ (Mobile Remote)**: `http://192.168.1.139:3000/remote`

---

## 📺 วิธีต่อใช้งานกับ Sony KD-55X8500G

### วิธีที่ 1: ต่อสาย HDMI (แนะนำที่สุด - เสียงตรง ไม่ดีเลย์)
1. เสียบสาย HDMI จากหลังคอมไปยังช่อง HDMI ของทีวี Sony
2. กด `Windows + P` บนคีย์บอร์ด เลือก **Extend (ขยายหน้าจอ)**
3. เปิดเบราว์เซอร์ไปที่ `http://localhost:3000/display` แล้วลากหน้าต่างไปไว้บนจอทีวี Sony
4. กดปุ่ม `F11` (หรือคลิกไอคอนเต็มจอที่มุมขวาบน) เพื่อให้แสดงผลเต็มจอ 55 นิ้ว

### วิธีที่ 2: เปิดผ่านเว็บเบราว์เซอร์บนทีวี Sony โดยตรง
1. บนทีวี Sony เปิดแอปเว็บเบราว์เซอร์ (เช่น Chrome หรือ TV Bro)
2. พิมพ์ URL: `http://192.168.1.139:3000/display`
3. หน้าจอทีวีจะเชื่อมต่อกับคอมและพร้อมเล่นเพลงทันที

---

## 📲 วิธีให้เพื่อนสั่งเพลงผ่านมือถือ
1. ให้มือถือทุกเครื่องต่อ Wi-Fi เดียวกันกับคอม
2. เปิดกล้องโทรศัพท์สแกน **QR Code** ที่ขึ้นอยู่บนหน้าจอทีวี
3. ใส่ชื่อเล่น แล้วเริ่มพิมพ์ค้นหาเพลงและสั่งเข้าคิวได้เลย!
